# ThunderPipe.Core.Tests

Suite made to test the different functionalities of [ThunderPipe.Core](https://github.com/WarperSan/ThunderPipe/tree/master/ThunderPipe.Core).

### Real Packages in Tests

In the suite, there are tests that use real packages as their test data. This was done for multiple reasons:
- Removes the step of coming up with a random yet valid name or team
- Diversifies the data to cover as much cases as possible

> [!IMPORTANT]
> If a developer wants their data removed from the data set, [let us know](https://github.com/WarperSan/ThunderPipe/issues) so we can handle it as best as possible.

There is no concrete way the data is gathered. We open Thunderstore, pick a random community (either popular or new), and pick a random package from the "Last Updated" sorting.

It's important to reiterate: there is no criteria. The picked package tend to simply be the one on top or one that looked funny.
